## 调用关系与关键规则

后续生产调用链：授权/工作区解析 → SessionRequest + WorkspaceContext → IProviderAdapter::makeLaunchSpec → ITerminalBackend::start → 启动/错误事件 → ISessionManager 会话快照。当前只有接口和测试替身，不能从测试通过推断这条生产链已完成。

- SessionId 默认无效，create 生成非空 UUID，parse 接受完整无大括号 UUID 并输出标准小写文本；非法、全零和缺失 ID 在边界拒绝。
- TerminalSize 默认 120 列、32 行，两维均限制 1..32767。尺寸校验不代表实际屏幕或平台资源允许任意面积。
- Result 始终存放成功值或 Error；先检查 isSuccess，再访问对应分支。错误文本必须脱敏，网络错误映射在 M3 实现。
- WorkspaceContext 表示调用边界已经解析的工作区，不是防伪授权凭据。Provider 不查客户端任意路径、不执行命令。LaunchSpec 参数保持原始逻辑值，平台启动边界转义一次。
- 进程 Creating/Running/Exiting/Exited/Failed 与订阅数量、写者独立。detach 只解除订阅与写权；terminate 需要显式确认和权限验证。启动尚未完成时，创建主体可以取消。
- 方法在对象所属的 Agent 控制线程调用，不允许等待管道/进程阻塞该线程。请求接受不等于完成，异步事件必须在请求返回之后交付。正常启动取消可以直接到 finished。
- outputAvailable 只表示有数据可读；takeOutput 按指定字节数拉取。字节可在 UTF-8/VT 序列中间分块，调用方不能逐块当完整文本解码。hasMore 表示继续读取，droppedBytes 明示截断。
- 新订阅读取当前保留输出，附加时已有输出也要通知；重新附加重置为新订阅。此能力不是无损重建屏幕或持久重放的保证。

## 验证入口与边界

使用 M1-01 的本机配置，根目录执行：

```powershell
cmake --build --preset debug
ctest --preset debug -R core.session_contracts
cmake --build --preset release
ctest --preset release -R core.session_contracts
```

测试使用真实 Qt 事件循环和元类型，但不启动业务线程或外部进程。queued 连接测试验证排队交付和值类型传递，不能替代真正跨线程并发测试。单写者、分离和终止的测试对象是内存替身，M2 必须对实际 SessionManager/ConPTY 重新验收。
