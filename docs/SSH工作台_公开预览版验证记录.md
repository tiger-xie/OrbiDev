# 公开预览版验证记录

目标版本：`0.1.0-preview.1`。日期：2026-10-21。

## 验证边界

本版为公开预览版，不是稳定版。真实家庭端功能已有用户验收反馈，但 Windows 11、全新 Windows 账户、长时间双端资源趋势及故障网络组合未完成全面验收。保留 SSH-04、FE-06 与 Qt 已知问题中的未执行项，不以打包成功替代实际验证。

原开发目录的终端阶段诊断改动与其他未提交工作保留。本版从独立 Git 工作区构建，不将其与已提交代码混合。发布包仅包含 Release 程序，不分发 Debug 运行库。

## 本轮证据

- 发布前对原开发目录已有 Release 终端程序执行一次独占回归：15/15、退出码 0、69.314 秒。该程序包含未提交阶段诊断，仅用于排查，不作为发布二进制证据。
- 历史初始化超时发生在终端网页加载阶段、SSH 启动之前；当前没有新的稳定复现或足够证据支持修改超时预算、自动重试或关闭 GPU。
- Qt 观察者竞态补丁没有应用到运行库；一次 Release 通过不能证明原生风险已修复。
- 独立工作区的 `8f1ba08` 源码 Release 全量构建通过（MSVC `/W4 /WX /analyze`），完整 CTest **14/14，65.83 秒**；该工作区没有原目录的阶段诊断改动。版本统一为 `0.1.0-preview.1` 后再次构建通过。
- 便携运行验证结果将在完成后补充；未完成前不标记通过。

## 用户可观察的风险

若终端初始化失败，请保留脱敏错误和版本信息，显式关闭该标签后新建会话。不要把重连视为恢复旧任务。绿灯只代表 SSH 进程运行，Ping 不可测也不直接代表 SSH 断开。

公开报告请勿包含密钥、连接配置或真实终端内容。详细技术风险见 [Qt 已知问题](../patches/README.md)。
