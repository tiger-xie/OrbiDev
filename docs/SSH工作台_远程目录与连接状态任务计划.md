## 已确认方案

目录第一版面向 Windows 家庭端，只读浏览和选择，保留手动输入；不上传、删除或新建文件夹。项目目录留空保持远程用户主目录。目录选择器以指定家庭主机为目标，提供磁盘列表、当前位置、上一级、主目录、刷新、子目录列表、选择此目录及取消。双击进入目录；加载时禁用确认；空目录可选择。已有路径失效需明确提示并由用户选择返回主目录，不静默替换。

查询服务与 UI 分离，以独立非交互 SSH 调用 PowerShell，不向工作终端注入命令、不启动 Claude。复用既有主机严格校验，未知或变化的指纹不得自动确认；认证失败指引连接设置。路径编码传递并使用 LiteralPath，只枚举当前层文件系统目录（含隐藏目录），不递归；超时 15 秒、输出上限 2 MiB、单层最多 5000 项，超限明确提示。结果包含规范化当前位置、父目录、主目录、磁盘与子目录；异步执行、取消及关闭后丢弃旧结果。

目录结果存入既有项目字段，无配置迁移。沿用切换目录后启动 Claude 的链路，增加实际工作目录测试；不存在、非文件夹或权限不足时停止，不回退。已有终端保持创建时的目录和主机。

当前标签文字后增加状态灯与 Ping 数字。绿色仅代表 SSH 进程运行，不代表 Claude 就绪或正在生成；准备、验证、关闭为黄色，失败/非零退出红色，空闲/正常退出灰色。Ping 独立于进程状态：成功显示 ms（小于 1 显示 <1 ms），首次检测中，失败超时或不可测；提示 ICMP 不通不代表 SSH 断开。

仅测量当前活动会话创建时绑定的主机；浏览主机切换不影响目标，关闭/退出后停止并显示 Ping —。立即检测，此后每 5 秒一次、单次 1 秒，不堆积；Windows ICMP API 支持 IPv4/IPv6，异步 DNS 不计入 RTT，不解析 ping.exe 输出。切换标签清空旧值，过滤迟到结果，安全结束工作线程，不保存历史。
