## 发布原则

- 首次对外版本暂定 `v0.1.0-preview.1`；如果真实双端、Windows 11 或长期稳定性验证不完整，使用 GitHub Pre-release，明确验证范围。
- 本轮按源码和运行包分别审查，不把“开源仓库创建成功”写成“稳定性全部通过”。
- 原 Client/Agent 暂停，保留历史代码但 README 突出 SSH 工作台。无关启动器和资料包不提交。
- 当前未提交的 TerminalView 阶段超时诊断只在单独核对其来源及验证后决定是否纳入，不覆盖原改动；其他未提交修改保留。
- 用户私钥、令牌、known_hosts、项目/连接配置、真实终端内容不进入仓库或发行包。
- Qt/Chromium/ConPTY 等保持原许可证，MIT 不覆盖第三方代码；运行包的动态库与对应源码/许可必须可获取。
