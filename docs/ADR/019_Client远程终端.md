# ADR-019：Client 远程终端接线

日期：2026-10-18。范围：M4-02，基于 M4-01 提交 f3c9231。

客户端对 FakeAgent 与真实 Agent 使用最小 IAgentClient 契约。协议和网络实现放在 core，界面只消费快照、异步结果与原始字节，不直接操作 Provider 或 ConPTY。保留模拟模式用于基础 UI 回归，真实连接必须明确配置端点与工作区 ID。

复用已验证的 xterm.js、FitAddon 和 Qt WebEngine/WebChannel，独立产品资源不改变 M0 POC。字节转 base64 仅跨 WebChannel，在 JavaScript 侧恢复 Uint8Array，防止跨包中文被提前解码损坏。

客户端断线、页面崩溃、显示积压或输出缺口时停止输入，明确显示错误；不通过自动重放输入“修复”不确定结果。现阶段采用有界积压及显式失败，不承诺任意吞吐下零中断；M5 再处理有限历史恢复，M7 继续压力验证。

设备凭据只在进程内存中使用，通过密码输入框或自动化环境变量传入；WebEngine 子进程启动前清除该环境变量。当前不实现配对 UI、DPAPI 或连接配置持久化。禁止普通公网地址与代理回退；跨设备连接依靠已有 Tailnet 保护和应用身份认证。

客户端协议未扩展退出码和工作区列表，因而本地公开参数只提供工作区候选，服务器 ACL 始终为最终授权依据；真实退出状态不伪造退出码。

流程、测试与限制见 [M4-02 说明](../M4-02_远程终端集成.md)。
