# ADR-017：Agent WebSocket 身份、连接与会话边界

日期：2026-10-17。范围：TASK-M3-02，基于 M3-01 提交 `f648917`。

## 决策

增加独立 RADAgentTransport 目标，依赖 RADCore、RADProtocol 和既定 Qt Network/WebSockets 模块。服务器借用 ISessionManager，同一控制线程运行，管理器必须晚于服务器销毁。apps/RemoteAgent 只组装配置、Provider、后端工厂和服务；固定 FakeCli 启动模板位于 providers，不允许网络请求指定可执行文件或任意参数。

Agent 默认不监听。显式配置后只允许绑定本机 IPv4 回环地址或本机 `100.64.0.0/10` 地址；后者是 Tailscale IPv4 地址范围约束，不代替部署者验证实际 Tailscale 身份、Grants 和防火墙。禁止通配地址、普通局域网与公网地址，不自动修改系统网络设置。

使用 HTTP Upgrade 的 `Authorization: Bearer <token>` 提供应用设备身份，令牌为 32 随机字节的小写十六进制表示。配置仅保留该 64 字符 ASCII 令牌的 SHA-256 摘要与客户端 ID；不把令牌放在 URL 或 RADP JSON 中，不输出凭据。对固定长度摘要比较，错误只返回公开信息。拒绝带 Origin 的浏览器连接，避免第三方网页访问本地 Agent。

本阶段采用显式配置的设备凭据，不实现配对 UI、DPAPI 凭据存储或热撤销。删除/替换配置中的设备摘要并重启 Agent 后撤销生效；重启会关闭原 ConPTY 会话，因此须先完成会话收尾。后续 M7 提供完整配对和凭据管理。

本轮采用 `ws://`，只用于回环或经部署确认的 Tailscale 私网链路；应用本身未实现 TLS，不能将普通网络转发或公网映射视为受保护链路。身份认证与工作区 ACL 分开：每个会话操作仍由 SessionManager 核验授权。

## 连接与会话生命周期

每个客户端身份最多一个活连接，重复连接拒绝，不抢占旧连接。认证之后还需完成 `auth.hello/auth.welcome` 版本协商才能调用业务操作。连接断开、超时或服务器 stop 只调用 detach，释放写权和订阅，不调用 terminate。

只有显式 `session.terminate` 路由可请求终止，响应表示受理，不伪造进程已经退出。退出状态仍由管理器事件报告。应用整体退出时管理器销毁将回收其拥有的进程，不能承诺 Agent 重启保留进程。

请求 ID 在每条连接内有界去重；达到额度要求重新连接。二进制输入按每个附加会话检查序号，防止同连接重放；此处不承诺跨连接的 exactly-once 输入。输出序号采用会话原始字节流的绝对偏移，重附加从现存有限历史重新开始。客户端须重建终端画面，不能直接把历史追加到旧画面；精确 ACK 恢复留给 M5。

当前没有分页协议，应用保留会话限制为 32 条（含终态），并验证最长合法字段仍可一次编码；底层 SessionManager 接口和默认配置不变。服务器遇到超帧列表时返回固定 busy 错误，不能因无法编码而反复断开客户端。未来提高上限必须同步分页或协议尺寸决策，不能只调大保留数量。

## 背压与保活

收包在 Qt WebSocket 层设置帧/消息上限，RADP 编解码再次检查。发送之前检查 socket 待写字节与新消息大小，超限断开该客户端并分离，不无限排队、不拖住其他会话。每轮输出有固定预算，剩余工作通过合并调度继续。

连接和协商有时间限制，活动连接通过 ping/pong 检测失联。会话心跳与连接保活分开：只有当前写者可续租，已过期的写权不能通过心跳自动抢回。输入、连接数、请求记录和输出队列均设上限。

审计仅记录固定事件与已配置身份，不记录请求体、终端内容或令牌；本阶段输出到控制台，不创建无限增长的日志文件。持久化诊断与轮转仍由 M5-02 实现。

配置与实际验证范围见 [M3-02 说明](../M3-02_AgentWebSocket服务.md)。
