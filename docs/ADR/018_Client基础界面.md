# ADR-018：Client 基础界面与 FakeAgent 边界

日期：2026-10-17。范围：TASK-M4-01，基于 M3-02 提交 `9031644`。

## 决策

采用已选深灰/青绿色视觉方向，使用原生 QMainWindow、QSplitter、项目会话树和 QTabWidget。主题统一集中应用，首版只提供 dark 并保存主题标识，不新增无实际选择的换肤控件或插件框架。

本阶段以 FakeAgent 驱动 UI 验收，演示身份始终可见，不自动连接真实家庭 Agent，不保存或要求用户提供真实令牌。服务端 M3-02 保持不变，客户端的网络适配及终端传输接入留到 M4-02。

连接状态、进程状态、附加状态与控制权分别显示。离线后保留最后已知进程状态，禁止发送操作，不把断线当作进程退出。一个 Session ID 对应一个标签，切换标签不分离；分离成功才移除标签，失败保留可见状态。终止必须明确确认，不能通过关闭窗口隐式终止。

UI 不承载 Provider 启动逻辑，FakeAgent 的异步结果与状态由独立控制对象提供。模拟数据不写入服务器，不把界面测试通过说成真实 CLI 或跨设备验收。

会话页展示当前上下文与终端尚未接入的说明，不以 QTextEdit 或静态输出冒充 VT 终端。M4-02 再组合已验证的 xterm.js/WebEngine 技术路线。原 M1 的 WebEngine 启动烟测保留为独立验收入口，不再作为默认主窗口。

## 验证原则

先用 Qt Test 覆盖新建、重复打开、分离、终止确认、取消、错误与断线，再运行真实 Qt 窗口截图检查。截图明确标注模拟场景；100%/125%/150% 缩放由独立进程验证，不能据此推断跨屏动态 DPI、系统阴影或窗口贴靠已通过。

当前实现和证据见 [M4-01 说明](../M4-01_QtClient基础界面.md)。
