# ADR-015：本地 SessionManager 与单写者租约

日期：2026-10-17。范围：TASK-M2-02，基于 M2-01 提交 9df7806；不实现网络鉴权、UI、持久化或真实 CLI Provider。

## 实现前计划

新增 core/session/SessionManager，实现现有 ISessionManager。通过构造参数注入静态 Provider 实例、可信工作区及客户端访问列表、后端工厂；核心只依赖 QtCore 与终端/Provider 抽象，不依赖 Windows。测试先定义可控替身场景，再接真实 WinConPtyBackend/FakeCli 验证。

只改管理器、构建注册、测试及相关文档；无公共抽象接口变更、无新增依赖。Agent 入口维持当前骨架，避免把 Provider 探测或网络配置塞进本任务。

## 状态与权限

- 创建仅返回受理的稳定 ID；不隐式附加、不取得输入权。Provider 与工作区必须在配置中，空授权列表默认拒绝，每次操作核验访问权限。客户端字符串不是鉴权证明，M3 负责认证后传入身份。
- 工作区配置由可信调用方提供，管理器按 ID 解析；当前拒绝非空 worktreeName。Windows 后端继续执行实际路径白名单验证。Provider 不得改变已选工作目录或终端尺寸。
- 进程状态与订阅分开；detach 仅移除订阅、释放控制权，不调用后端 terminate。只有显式 terminate 才停止会话；Creating 允许创建者取消，Running 需要当前写者。
- 活跃额度默认 4，直到 finished 才释放，避免 Failed 但仍在清理时提前超额。终态记录/有界历史留在内存，默认最多 128 条，满后明确拒绝新建；清理/持久化策略留给后续任务，不悄悄删除记录。

## 控制权租约

采用单调时钟，默认 30 秒。成功输入、resize 或原写者重复 ReadWrite attach 续租；后续网络心跳可调用已有附加入口续期，不预先新增协议。租约到期释放写者但保留只读订阅，不终止进程。重新申请写权先 detach，再 ReadWrite attach；仍遵守模式变更须先分离的既有契约。不支持强制抢占。

定时器处理空闲到期，控制操作也检查实际到期时间，避免事件循环延迟导致旧写者继续输入。

## 输出与所有权

管理器拥有无 parent 的后端。每会话保留有界原始字节历史，默认 1 MiB；每订阅者独立游标与丢弃量，默认最多 16 名订阅者。后端丢弃与管理器截断均显式报告，不能把不连续字节伪装成完整流。

订阅通知合并并带订阅代次，detach 后失效；重新附加已有历史时也异步通知。消费慢不会阻塞其他订阅者或会话。结束时先归并后端尾部，再发 finished；析构只作为停止所有后端的兜底，不能代表客户端分离。

## 验证计划

- 单元：同步拒绝、异步失败、Creating 取消、权限、容量回收、单写者续租/过期、输出独立游标/截断/通知重入及后端错误传播。
- 集成：真实 3 会话输入隔离、所有客户端分离后仍运行、同 ID 重附加可继续输入、显式终止与尾部输出。
- Debug/Release 构建、MSVC 静态分析、格式检查及相关回归；已有 WebEngine POC 超时单独保留，不视为管理器测试结果。
