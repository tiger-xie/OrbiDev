重点覆盖：切换浏览主机后打开失败标签设置、已删除主机、取消重连、重复重连、旧输出保留、晚到信号、退出码与错误标题不误导。真实终端初始化失败保留明确原因，不将 UI 截图视为 SSH 成功证据。

## 已实现的边界

连接设置按显式主机 ID 编辑，保存或取消都不切换当前浏览主机；该主机缺失时反馈原因。重连按完整目标快照寻找准备或运行中的标签，匹配包含主机/项目 ID、目录、地址、用户、端口、身份文件路径和指纹。已退出、终端失败或关闭中的标签不能成为复用目标。首次新建仍需默认“否”的确认，旧标签及输出不删除。

状态展示只使用会话信号与本地错误：退出码 255 不被归类为认证失败；终端故障优先于随后到来的 SSH 退出；设置入口不把当前下拉框的另一台电脑作为编辑对象。
