## 实现与简化

- 公司端四页使用统一卡片分区；248 逻辑像素的步骤轨道显示圆形编号、连接线、阶段名称和简短状态，当前步骤以青绿色边线定位。
- 环境检查完成仅表示客户端可用，不把 Tailscale 未确认在线描述为网络已连通。
- 授权页显示设备与公钥指纹，复制/导出操作在摘要卡片内；公钥正文默认收起，可展开查看。家庭端操作拆成三条编号说明。
- “已完成授权，下一步”记录用户声明；侧栏明确显示“已声明授权，待验证”，只有连接测试成功才显示验证通过。
- 身份重检统一清除授权声明和旧连接结果；复制、导出等反馈不改变业务步骤结果。复用一个失效方法，删除两处分散重复处理。
- 底栏固定；公司端标题、卡片、轨道和编号样式集中到 `setup.qss`。新 SVG 为本项目自行绘制，通过根 qrc 加载，无新增依赖。
- 家庭端保留原步骤和页面内容，沿用共用底栏。未修改服务接口、主机信任或授权写入逻辑。

| 选择器/控件 | 职责 |
| --- | --- |
| `role=setupStep`、`current`、`state` | 当前阶段与实际完成/失败状态 |
| `role=stepBadge/stepLine/stepName` | 圆标、连接线与阶段标题 |

## 验收步骤与剩余风险

1. 打开首次配置，检查四页卡片、步骤圆标、当前高亮与底栏；环境和身份未检查时不能跳过前置条件。
2. 使用已有身份到授权页，核对设备与指纹；展开/收起公钥正文，检查复制、导出仍仅处理公钥。
3. 点击“已完成授权，下一步”，侧栏应显示待验证；测试连接成功后才显示连接通过。
4. 更换本机身份或编辑连接目标，确认旧连接结果不再允许直接保存；操作期间按钮禁用，关闭仍被拦截。
5. 在 150% 或较小窗口下滚动页面查看所有内容；错误文字应可读，底部下一步保持可见。
