## 实现与边界

- `tools/SshSetup/WindowFrame.h/.cpp`：公司端、家庭端、工作台共用的 40 逻辑像素标题栏。提供标题、图标、最小化、最大化/还原、关闭、双击标题最大化、Alt+Space 与标题右键系统菜单。
- 移动和八方向缩放使用 Qt 5.15 的系统移动/缩放接口；不编写手动移动窗口循环。关闭按钮仍调用原窗口的 `close()`，保留原关闭确认。
- `SetupWindow.cpp` 和 `WorkbenchWindow.cpp` 仅接入标题栏。未修改 SSH 连接、授权、终端和页面业务接口。
- `resources/style/window.qss` 与 `resources/icon/window/*.svg` 登记到根 `OrbiDev.qrc`；`SetupTheme.cpp` 统一加载。未新增第三方依赖。
- `WindowFrameTests.cpp` 覆盖八方向命中、标题同步、关闭拒绝、最大化边界、还原、最小化和双击；原生鼠标测试显式开启并检查前台窗口。

本项仅替换窗口顶部，不提前实施 UI-03～UI-07 的页面布局。标题不换行，窄窗口优先保留操作按钮；当前三个应用固定标题可完整显示。

## 实机检查步骤

1. 分别启动公司端设置、家庭端设置和工作台，检查顶部图标、标题、三个按钮；按 Tab 检查按钮焦点提示。
2. 拖动标题栏；在普通窗口的四边和四角调整尺寸，确认没有卡住或误触页面操作。
3. 双击标题最大化及还原，确认最大化不覆盖任务栏，恢复后位置尺寸正确。
4. 最小化后点击任务栏恢复；用 Alt+Space 和标题右键打开系统菜单，检查移动、大小、还原、关闭。
5. 工作台存在会话时分别使用关闭按钮和 Alt+F4，确认原关闭确认依然出现，取消后窗口和会话保留。不要为了界面验收主动结束重要远端任务。
6. 在 100%／150% 下重复关键操作；跨屏和 Windows 11 行为单独记录。

## 简化与剩余风险

三个程序复用一个局部标题栏组件，样式只保留在资源文件，系统菜单复用 Windows 原生菜单。没有引入独立主题框架或改变会话关闭策略。
