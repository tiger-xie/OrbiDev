# UI-01：资源与公共视觉基础验收

日期：2026-10-20。范围：基础样式与资源，不含标题栏、向导布局和工作台结构重排。

## 实现与简化

- 根 `OrbiDev.qrc` 登记三份 QSS 和三个自行绘制的 SVG，公共入口 `applySetupTheme` 显式初始化静态库资源。
- `resources/style/base.qss` 管理公共字段、按钮、菜单、复选框、滚动条、提示、焦点与禁用规则。
- `resources/style/setup.qss` 管理既有步骤角色；`workbench.qss` 管理既有项目列表、标签和工作台区域。
- 删除 `SetupTheme.cpp` 与 `WorkbenchWindow::buildUi` 的内联样式块；错误反馈使用 `error` 属性并重新应用样式，不再拼接临时 QSS。
- `resources/icon/common/` 保存 app、check、chevron-down SVG，来源说明随目录保存。窗口图标、复选框和下拉框使用资源路径。
- 保留调色板供未被 QSS 覆盖的控件使用；继续使用现有主题入口，不创建新主题框架。
- 打包必需文件新增 Qt SVG 运行库及图标/图片插件检查；这些插件已在现有 Qt 部署中使用，无新增下载依赖。
