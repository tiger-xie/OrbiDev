## 验收边界

- 浏览主机与当前终端的所属主机分别展示，不能在切换浏览主机时伪造当前标签的目标或连接状态。
- SSH 运行中仅表示本地 SSH 进程启动；不能显示未经证实的远端认证或 Claude 就绪。
- 双击项目复用已有终端，新建终端明确创建额外会话；切换主机保留原标签和输出。
- 项目勾选与当前选中保持独立；编辑/移除保留键盘可达入口。
- 长名称和目录不能撑破窗口；完整目标可通过提示查看。状态区保留复制粘贴提示及关闭/断线风险说明。
- 预览无网络、无真实配置写入；真实终端稳定性与静态外观分开验证。

- 顶部保留主机浏览、当前标签所属主机与状态、设置、新建终端。外观和字号调整移入现有设置菜单，原字号快捷键保留。

- 标签下增加 `terminalLocation` 主机/目录信息条，内容来自创建时快照；编辑项目不改变已有会话的目标。顶部 `hostSummary` 显示活动标签，与浏览主机下拉框分离。
- 底栏呈现 SSH、UTF-8、标签数量和复制粘贴快捷键；“断线说明”保留关闭/重连的真实限制。
- QSS 集中在 `resources/style/workbench.qss`；新增 Lucide plus/settings/terminal 图标资源固定上游提交并附完整许可，目录与关闭图标复用已有资源，不增加依赖。

## 静态审查与视觉修正

只读审查确认：活动标签主机和目录使用快照；项目快捷键作用域为 WidgetShortcut；最后标签关闭刷新摘要；移除项目保留既有标签。原终端输入、会话创建、退出与重连链路保持不变。

首轮实际截图发现两层文字裁切。最终确认 Qt 5.15.2 的 initStyleOption/displayText 会把换行转换为 U+2028，委托再按原换行拆分时未能分为两行，导致名称和目录挤进同一绘制区域。修复为从模型原始 DisplayRole 取文字拆行，原生样式继续负责背景、焦点和勾选；文字使用整行可用区域。标签预览选中项同步到首个样例标签。此问题由实际截图和临时几何/文字诊断定位，临时诊断不保留。

## 手工验收步骤

1. 用 `Start-SshWorkbench.cmd` 启动，检查顶部、项目导航、设置菜单、底部说明。设置菜单应仍能打开外观、调整字号与管理主机。
2. 双击项目应复用原标签；“新建终端”应增加一个标签。项目勾选与选中相互独立，批量打开只处理当前主机的勾选项目。
3. 保留一台主机的活动标签，切换浏览另一台主机；顶部“当前标签”仍显示旧标签的所属主机，点击另一标签时列表应随该标签联动。
4. 在项目列表用右键/F2 编辑、Delete 移除；在终端内使用这些按键不应触发项目操作。编辑目录后已有标签的路径栏仍显示创建时目录。
5. 100%／150% 及窄窗口检查项目名称/目录、标签、状态栏；长文字可从提示中查看。关闭标签、程序退出确认及断线说明继续按原逻辑工作。
