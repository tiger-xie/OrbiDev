## 实现与简化

项目、主机、外观复用现有 WindowFrame 的关闭专用模式，标题栏与正文、底栏分层。项目默认 600×520，480×440 时正文滚动；主机默认最大 680×600 并按桌面收缩，480×440 时底栏始终可见。外观保留原有主题和全局字号选项。

- 新建项目的“保存后打开终端”默认不勾选；只有明确勾选且落盘成功后才打开目标主机的终端。编辑项目不自动启动。
- 主机保存回调复用 WorkbenchStore 原子保存，失败保留字段与窗口，修复后可重试。
- 外观先保存候选字号再应用，失败时原字号不变；取消不写入。
- 安全确认仍使用 QMessageBox，深色正文和按钮统一，默认“否”；未将安全确认改为自绘窗口。
- 复用公共窗口与保存接口，没有新增依赖或通用表单框架。数字输入框消除内部重复边距，并复用/补齐上下箭头资源。
